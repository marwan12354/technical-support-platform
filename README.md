# 🟢 منصة مساند | الدعم التقني الداخلي
نظام حوكمة إداري مخصص لموظفي المديرية المكلفة بالنهوض بحقوق الأشخاص في وضعية إعاقة.
يهدف لتوحيد الإبلاغ، تتبع الحل، وقياس الأداء وفق SLA ≤ 1 ساعة (عاجل) و ≤ 4 ساعات (عادي).

## 🛠️ التشغيل المحلي
1. `npm install`
2. انسخ `.env.example` إلى `.env` وعدل بيانات الاتصال
3. `npx prisma generate && npx prisma db push`
4. `npm run dev`

## 📜 الامتثال
- القانون 97.13 (المادة 33)
- القانون 09.08 (حماية البيانات)
- معايير WCAG 2.2 AA
- خطة BCP (استعادة ≤ 4 ساعات)
